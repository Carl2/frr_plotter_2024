Come on!
First we have
[A B C "D-E"]

Use two delimiters ['\t',"-"] → [fnT,FnM]
Run the fnT(list) ⇢ [A,B,C,"D-E"]

Next we run each item in the list through fnM
$fn(list, fn) \Rightarrow fn(list+1,fn)$
